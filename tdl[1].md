## 👋 Bienvenue

To-Do List est une liste de tâches qui propose trois affichages : liste, papier collant et widget. Vous ajoutez, cochez, modifiez et supprimez des tâches. Tout est enregistré dans le localStorage.

---

## ✨ Ce que vous trouverez

**Trois modes.**  
Liste simple, papier collant jaune, widget sombre. Le changement se fait en haut à droite.

**Ajout et modification.**  
Entrez une tâche, appuyez sur Add. Double-cliquez sur une tâche pour la modifier.

**Filtres.**  
Affichez tout, seulement les tâches actives, ou seulement les tâches terminées.

**Barre de progression.**  
Une ligne fine montre la part de tâches terminées.

**Sauvegarde locale.**  
Les tâches sont conservées dans le localStorage. Le mode d'affichage aussi.

---

## 🧭 Comment ça marche

**1. Ouvrez le fichier.**  
La liste s'affiche, vide au premier lancement.

**2. Ajoutez une tâche.**  
Tapez dans le champ et appuyez sur Add ou Entrée.

**3. Cochez ou modifiez.**  
Cliquez sur la case pour marquer terminé. Double-cliquez sur le texte pour le modifier.

**4. Changez de mode.**  
Utilisez les trois icônes en haut à droite.

C'est tout.

---

## 🛠️ Petits coups de main

**Où sont mes tâches ?**  
Dans le localStorage du navigateur, sous la clé `mc88.todos.v1`.

**Comment modifier une tâche ?**  
Double-cliquez sur le texte. Appuyez sur Entrée pour valider, Échap pour annuler.

**Que fait Clear completed ?**  
Il supprime toutes les tâches cochées. Les tâches actives restent.

**Est-ce que je peux l'utiliser hors ligne ?**  
Oui. Le fichier ne charge rien depuis internet.

## 👋 Welcome

To-Do List is a task list that offers three views: list, sticky note and widget. You add, check, edit and delete tasks. Everything is saved to localStorage.

---

## ✨ What you'll find

**Three modes.**  
Plain list, yellow sticky note, dark widget. Switch with the buttons in the top right.

**Add and edit.**  
Type a task, press Add. Double-click a task to edit it.

**Filters.**  
Show all, only active tasks, or only completed tasks.

**Progress bar.**  
A thin line shows the share of completed tasks.

**Local save.**  
Tasks are kept in localStorage. The view mode is too.

---

## 🧭 How it works

**1. Open the file.**  
The list shows, empty on first launch.

**2. Add a task.**  
Type in the field and press Add or Enter.

**3. Check or edit.**  
Click the box to mark done. Double-click the text to edit it.

**4. Change the mode.**  
Use the three icons in the top right.

That's it.

---

## 🛠️ A little help

**Where are my tasks?**  
In the browser's localStorage, under the key `mc88.todos.v1`.

**How do I edit a task?**  
Double-click the text. Press Enter to save, Escape to cancel.

**What does Clear completed do?**  
It removes every checked task. Active tasks stay.

**Can I use it offline?**  
Yes. The file loads nothing from the internet.
